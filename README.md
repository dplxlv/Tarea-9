Proyecto de herencia e interfaces en Java.

Se utilizo una clase abstracta llamada Vehiculo para reutilizar atributos y metodos comunes.
Las clases Auto, Moto y Camion heredan de Vehiculo usando extends.
La interfaz Electrico fue implementada por Auto usando implements.
En el main se utilizo polimorfismo con un arreglo Vehiculo[] y instanceof para identificar objetos electricos.



Proyecto de figuras geometricas usando Programacion Orientada a Objetos en Java.

Se utilizo una clase abstracta llamada Figura para reutilizar atributos y metodos comunes.
Las clases Circulo, Rectangulo y Triangulo sobrescriben los metodos area() y perimetro() usando @Override.
En el main se utilizo polimorfismo con un arreglo de tipo Figura[].
El codigo fue organizado en clases separadas para mantener claridad y evitar repeticion innecesaria.



Proyecto realizado usando herencia, clases abstractas, interfaces y polimorfismo en Java.

La clase abstracta Empleado contiene atributos y metodos comunes para reutilizar codigo.
Las clases EmpleadoPorHora, EmpleadoFijo y EmpleadoComision sobrescriben calcularSalario() usando @Override.
La interfaz Bonificable fue implementada por EmpleadoFijo y EmpleadoComision para calcular bonos.
En el main se utilizo un arreglo Empleado[] y instanceof para identificar objetos Bonificables.
El codigo fue separado por clases para mantener organizacion y claridad.
